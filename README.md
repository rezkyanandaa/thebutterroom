# The Butter Room

Static GitHub Pages-ready bakery shop.

Files:
- index.html
- style.css
- script.js
- assets/favicon.svg

Upload all files/folders to the root of your GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from branch → main → / (root).

The shop, filters, cart, delivery rules, WELCOME10 promo, drinks customization, checkout and WhatsApp order flow are client-side and require no backend.
